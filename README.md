# Family Management Frontend (`familyfund_app`)

Ứng dụng đa nền tảng (**Flutter Web & Mobile Android/iOS**) phục vụ **Hệ thống Quản lý Sự kiện và Quỹ Đại Gia Đình**, hỗ trợ đầy đủ cả **Phân hệ Thành viên / Con cháu** và **Phân hệ Quản trị / Trưởng tộc & Ban Tổ Chức** trên cùng một codebase theo kiến trúc **Feature-first + Clean Architecture**.

---

## 🚀 Khởi Chạy Nhanh

```bash
# 1. Cài đặt dependencies
flutter pub get

# 2. Kiểm tra static analysis
flutter analyze

# 3. Chạy kiểm thử tự động
flutter test

# 4. Chạy trên Web (Chrome/Edge)
flutter run -d chrome

# 5. Chạy trên thiết bị / máy ảo Android hoặc iOS
flutter run
```

> 📖 Xem chi tiết kiến trúc phân lớp, Dual-RBAC và cấu trúc thư mục tại **[docs/FRONTEND_ARCHITECTURE.md](./docs/FRONTEND_ARCHITECTURE.md)**.
